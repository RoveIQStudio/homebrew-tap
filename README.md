# RoveIQ Homebrew tap

```sh
brew install roveiqstudio/tap/rovemaps
```

`rovemaps` is the command-line tool for [RoveMaps Studio](https://rovemaps.studio). See [RoveIQStudio/rovemaps-cli](https://github.com/RoveIQStudio/rovemaps-cli) for what it does and its license.

The formulas here are updated by each release.
